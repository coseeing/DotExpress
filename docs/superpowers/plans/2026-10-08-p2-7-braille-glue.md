# Braille Glue Cleanup (P2-7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The two first-party braille glue modules stop configuring the root logger at import (`braille.tables` and the generated `braille.louis_helper` both log through `logging.getLogger(__name__)`), `braille.tables.get_table_directory(source)` replaces the helper's read of the private `_tablesDirs`, the translation runtime provider creates, injects and closes one `MathCATAdapter` per runtime (the `get_shared_mathcat_adapter()` singleton is deleted), `getDefaultTableForCurLang` is kept on purpose (D4), and the unit test suite stops appending to the real `client/log/*.log` files. Refactor: no msgid change (353, same set), same conversion output, both fixtures untouched, no change to `__tables.py` or to vendored NVDA files other than the regenerated runtime helper snapshot.

**Architecture:** Five commits in the spec's order. Task 1 characterizes the generated helper's table resolver (loaded from the tracked snapshot `vendor/nvda/liblouis/runtime/louis_helper.py` with a fake `braille.liblouis`) and the default math translator wiring; a throwaway mutant runner shows 6 deliberate breakages are each caught. Task 2 changes `braille.tables` red-first (D1, D4, D5; a CRLF file edited byte-exactly). Task 3 changes the two replacement strings in `scripts/sync-nvda.py` `_adapt_helper` red-first and regenerates only the runtime helper snapshot with `_adapt_helper` (never the full sync); a snapshot test keeps the snapshot equal to the adaptation, and the installed, git-ignored `client/braille/louis_helper.py` (old content until Windows reruns `scripts\install.bat`) is checked to still work. Task 4 moves MathCAT ownership to the provider red-first (D6-D10); 7 mutants of the new lifecycle are caught. Task 5 (independent, droppable) adds a test helper that swaps file handlers for a `NullHandler` per test module.

**Tech Stack:** Python 3 standard library (`unittest`, `unittest.mock`, `importlib`, `ast`, `ctypes`, `logging`, `subprocess`, `functools`, `contextlib`). wxPython is not installed; `tests/test_dual_view_frame.py` keeps its `tests/wx_stub.py` scope. The real liblouis DLL and MathCAT `.pyd` cannot load on Linux; the new tests use a fake `braille.liblouis` and recording MathCAT adapters.

**Spec:** `docs/superpowers/specs/2026-10-08-p2-7-braille-glue-design.md` (authoritative, commit `030ea83`). Corrections and refinements decided here are listed below.

## Review Focus

1. **A Windows checkout that has not rerun `install.bat`.** The installed helper still reads `braille_tables._tablesDirs.get(...)`; `_tablesDirs` must stay and keep the same contents, or text translation of registered bare table names breaks there. `installed_helper_check.py` (Task 3, Task 6) runs the resolver characterization against that file.
2. **The snapshot must be what a sync would write.** A hand edit or a CRLF conversion of `vendor/nvda/liblouis/runtime/louis_helper.py` would ship to Windows through `install.bat` and be lost at the next sync. `VendorHelperSnapshotTests` (mutants `snapshot-edited-by-hand`, `snapshot-crlf`).
3. **Root logger state leaking between tests.** The step-1 resolver tests load a helper that (before Task 3) calls `basicConfig`; `vendor_helper()` puts back the root handlers and level, and the red/green root checks run in fresh interpreters so earlier tests cannot mask them. 20 shuffle seeds in Task 6.
4. **A failed MathCAT load must not leave its DLL directory registered** and a late caller must not reopen a closed adapter. `test_default_math_factory_normalizes_native_runtime_errors`, `test_unexpected_math_initialize_error_closes_the_adapter_and_propagates`, `test_closed_adapter_refuses_to_load` (mutants `failed-initialize-not-closed`, `closed-adapter-still-loads`).
5. **Shutdown order.** `runtime.close()` must close MathCAT before liblouis `terminate()` (reverse registration order, D10). `test_runtime_close_closes_mathcat_before_liblouis` (mutant `math-translator-not-closable`).

+"""Keep tests from appending to the real application log files.
+
+``log.get_logger`` binds a ``FileHandler`` in ``<root>/log/`` when a module first
+creates its logger, so a test that makes production code log would write there.
+"""
+
+import logging
+from collections.abc import Callable
+
+
+def isolate_file_logs(*names: str) -> Callable[[], None]:
+    """Swap the handlers of the named loggers for a ``NullHandler``.
+
+    Sets ``propagate`` to ``False`` as well. Works for loggers that do not exist
+    yet: ``log.get_logger`` then finds a handler and adds no file handler.
+    Returns a function that puts back the exact previous handlers and ``propagate``.
+    """
+    saved = []
+    for name in names:
+        logger = logging.getLogger(name)
+        saved.append((logger, list(logger.handlers), logger.propagate))
+        for handler in list(logger.handlers):
+            logger.removeHandler(handler)
+        logger.addHandler(logging.NullHandler())
+        logger.propagate = False
+
+    def restore() -> None:
+        for logger, handlers, propagate in reversed(saved):
+            for handler in list(logger.handlers):
+                logger.removeHandler(handler)
+            for handler in handlers:
+                logger.addHandler(handler)
+            logger.propagate = propagate
+
+    return restore
