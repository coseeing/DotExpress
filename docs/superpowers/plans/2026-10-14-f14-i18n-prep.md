# Interface-Language Preparation, HTML `lang` and the Settings Backup Message (F-14) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ] `) syntax for tracking.

**Goal:** The three i18n items the user decided on 2026-10-14 (U1-U3): no interface text is translated when a module is imported any more, and `i18n` reports the interface language (item 7, F-12 review M-7); the Dual View window, its browser copy and every exported Dual View HTML file declare that language, `lang="zh-TW"` (item 4); the "settings not saved" box of a failed `config.json.bak` backup gives a translated reason by kind of error and names the backup file, without the operating system's text and the temporary file name (item 8). Nothing else the user sees changes. Two new strings (N1, N2), F-12's string 22 drops out: 408 msgids.

**Architecture:** Four commits, each red first, in the spec's migration order. Task 1 turns `i18n._` into a module function that looks up the active catalog at each call and adds `SOURCE_LANGUAGE`, `set_language`, `current_language` and `html_language_tag` (D1). Task 2 makes the 15 import-time texts `N_` msgids, translated where they are read: `about.about_message()` and `copyright_text()` (D2), `entry_type_label()` and `entry_type_choices()` for the dictionary editor (D3), the settings panels' and dialog's titles (D4); two guards (an AST scan and an import probe in a subprocess) keep import-time translation out (D5). Task 3 makes `lang` a required keyword of `render_dual_view_html`, and the two producers pass `html_language_tag()` (D6). Task 4 splits the `BACKUP_FAILED` reason by `config.is_access_error` into N1 and N2 and fixes the catalogs (D7, D8). Task 5 verifies (suite, shuffled order, catalogs, fixtures, application data, 20 mutants); Task 6 builds the exe and runs GUI items 141-144 (145 stays manual).

**Tech Stack:** Python 3.13 standard library (`gettext`, `ast`, `unittest`, `unittest.mock`), wxPython 4.2.5 (only imported by the import probe), GNU gettext 0.23 (`xgettext`, `msgmerge`, `msgfmt`), Git Bash `unix2dos`. Windows 11, the main checkout's `client\.venv` (PyInstaller 6.21.0). The GUI checks use pywinauto 0.6.9 and psutil in a separate venv.

**Spec:** `docs/superpowers/specs/2026-10-14-f14-i18n-prep-design.md` (+ `_zh-TW.md`), with the section "Corrected after planning (F-14, 2026-10-14)" / 「規劃後的修正（F-14，2026-10-14）」 added in the plan commit (both languages). """Condense unittest output read from stdin (throwaway, not committed).

Keeps the FAIL/ERROR headers and exception lines, cut to 160 characters (a cut line is

timing and the final OK/FAILED line, so that outputs can be compared with the plan. The

also in repr form with doubled backslashes) as <tmp>; random temporary-file suffixes as

when unittest's diff has cut the repr down to its last characters. F-12 addition: the
last character of a cut temporary folder's random name before "/sources/" (a cut diff shows
only the end of the name) as <c>.
"""
import re
import sys
from pathlib import Path

CLIENT = str(Path.cwd())
CLIENT_REPR = CLIENT.replace("\\", "\\\\")
TMPDIR = re.compile(r"[A-Za-z]:(?:\\\\|\\)(?:[^'\"\s]*?(?:\\\\|\\))?tmp[a-z0-9_]{8}")
RANDOM_TMP = re.compile(r"(\.[\w.]+?\.(?:dep|csv|py|json|brl|html)\.)[a-z0-9_]{8,16}(\.tmp)")
ADDRESS = re.compile(r" at 0x[0-9A-Fa-f]+>")
CUT_ADDRESS = re.compile(r"(\[\d+ chars\])[0-9A-F]{1,16}>")
CUT_TMP = re.compile(r"[a-z0-9_]((?:/|\\\\|\\)sources(?:/|\\\\|\\))")

"""Set the msgstr of active .po entries and clear their fuzzy flag (throwaway, not committed).

Usage: python -I set_msgstr.py <file.po> <msgid> <msgstr> [<msgid> <msgstr> ...]

Each msgid must be an active (not obsolete) entry of the file, exactly once. Its msgstr
becomes the given text on one line and "fuzzy" leaves its "#," flags (the line goes when no

import sys
from pathlib import Path

sys.stdout.reconfigure(encoding="utf-8")


def quote(text: str) -> str:
    return '"' + text.replace("\\", "\\\\").replace('"', '\\"').replace("\n", "\\n").replace("\t", "\\t") + '"'


def main() -> int:
    path, *pairs = sys.argv[1:]
    if not pairs or len(pairs) % 2:
        sys.exit("give msgid and msgstr pairs")

    crlf = "\r\n" in raw
    blocks = raw.replace("\r\n", "\n").split("\n\n")

        found = []
        for index, block in enumerate(blocks):
            lines = block.split("\n")
            if any(line.startswith("#~") for line in lines):
                continue

"""Apply the File: and Edit: blocks of one step of the F-14 plan (throwaway, not committed).

Usage: python apply_blocks.py <plan.md> <repo> <T> "<task>" "<step>"
  for example: python apply_blocks.py plan.md D:/workspace/DotExpress-f14 <T> "Task 1" "Step 1"

The step is the "- [ ] **Step N" item under the "### Task N" heading. A File: block is
written as is (a path starting with $T goes under <T>, any other path under <repo>); an
Edit: block is the line "Edit: `path`" and the next two fenced blocks, the old text and
its replacement. The old text must occur exactly once in the file at that point
(compared with CRLF as LF; the file keeps its line endings). Blocks are applied in plan
order. Prints one line per block; stops with exit status 1 at the first block that does
not apply. Reads and writes bytes, so escapes such as \\u81fa stay as they are.
"""
import re
import sys
from pathlib import Path

FENCE = re.compile(r"^(`{3,})[\w-]*\s*$")


def fenced(lines, start):
    """(body, index after the closing fence) of the first fenced block at or after ``start``."""
    index = start
    while not FENCE.match(lines[index]):
        index += 1
    fence = FENCE.match(lines[index]).group(1)
    end = index + 1
    while lines[end].strip() != fence:
        end += 1
    body = lines[index + 1:end]
    return "".join(line + "\n" for line in body), end + 1


def main() -> int:
    plan, repo, tdir, task, step = sys.argv[1:6]
    lines = Path(plan).read_bytes().decode("utf-8").replace("\r\n", "\n").split("\n")
    in_task = in_step = False
    applied = 0
    index = 0
    while index < len(lines):
        line = lines[index]
        if line.startswith("### "):
            in_task = line.startswith(f"### {task}:")
            in_step = False
        elif line.startswith("- [ ] **Step"):
            in_step = in_task and line.startswith(f"- [ ] **{step}:")
        match = re.match(r"^(File|Edit): `([^`]+)`$", line) if in_step else None
        if not match:
            index += 1
            continue
        kind, path = match.groups()
        target = Path(tdir) / path[3:] if path.startswith("$T/") else Path(repo) / path
        if kind == "File":
            body, index = fenced(lines, index + 1)
            target.parent.mkdir(parents=True, exist_ok=True)
            target.write_bytes(body.encode("utf-8"))
            print(f"wrote {path}")
        else:
            old, index = fenced(lines, index + 1)
            new, index = fenced(lines, index)
            raw = target.read_bytes().decode("utf-8")
            crlf = "\r\n" in raw
            text = raw.replace("\r\n", "\n")
            count = text.count(old)
            if count != 1:
                print(f"edit of {path} (plan line {index}): old text found {count} times")
                return 1
            text = text.replace(old, new)
            target.write_bytes((text.replace("\n", "\r\n") if crlf else text).encode("utf-8"))
            print(f"edited {path}")
        applied += 1
    print(f"{applied} blocks applied ({task}, {step})")
    return 0 if applied else 1


if __name__ == "__main__":
    sys.exit(main())

def _import_time_translation_lines(tree: ast.Module) -> list[int]:
    """Lines of the translating calls that run when the module is imported (F-14 D5).

    That is every call outside a function body: at module level, in a class body, in a
    default argument or in a decorator. Function and lambda bodies run later.
    """
    lines = []

    def visit(node: ast.AST, in_body: bool) -> None:
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.Lambda)):
            arguments = node.args
            for expression in [*getattr(node, "decorator_list", []), *arguments.defaults, *arguments.kw_defaults]:
                if expression is not None:
                    visit(expression, in_body)
            for statement in node.body if isinstance(node.body, list) else [node.body]:
                visit(statement, True)
            return
        if isinstance(node, ast.Call) and not in_body:
            function = node.func
            name = function.id if isinstance(function, ast.Name) else getattr(function, "attr", None)
            if name in TRANSLATING_CALLS:
                lines.append(node.lineno)
        for child in ast.iter_child_nodes(node):
            visit(child, in_body)

    visit(tree, False)
    return sorted(lines)
