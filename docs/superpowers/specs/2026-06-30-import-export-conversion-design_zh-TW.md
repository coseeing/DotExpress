# 匯入對話框簡化與匯出時轉換設計

## 摘要

這項變更會移除文件工作流程中的背景自動轉換功能，但保留在視窗標題顯示目前文件名稱的行為。同時也會簡化文件匯入流程，將原本依格式分組的匯入子選單改為單一檔案對話框，讓使用者直接在對話框中選擇檔案類型篩選條件。

這次調整的主要目標，是避免匯入文件時因自動轉換造成介面卡住。點字轉換不應再於匯入、儲存、開啟或其他背景流程中自動執行，而是只在使用者明確執行「轉換」，或匯出時確實需要點字輸出時才進行。

## 目標

- 保留視窗標題顯示目前文件名稱的行為。
- 移除所有背景自動轉換行為。
- 自動轉換只在匯出確實需要點字輸出時執行。
- 匯出觸發轉換時，沿用現有執行緒化轉換流程與「轉換中」對話框。
- 避免在「全部匯出」時重複跳出成功訊息。
- 將匯入格式子選單改為單一「匯入」指令，並在檔案對話框中提供檔案類型篩選。

## 非目標

- 不加入背景轉換佇列、註冊表或待處理工作系統。
- 不重新設計手動「轉換」流程，僅在需要重用於匯出時調整完成訊息控制。
- 不變更支援的匯入或匯出格式。
- 不修改文件封裝格式，只維持目前對待轉換點字中繼狀態的保存方式。

## 使用者可見行為

### 視窗標題

- 沒有開啟文件時，視窗標題顯示為 `DotExpress`。
- 有開啟文件時，視窗標題顯示為 `<文件名> - DotExpress`。
- 開啟、切換、重新命名、刪除或清空目前文件時，都必須同步更新標題。

### 儲存與一般編輯流程

- 儲存目前文件時，不可觸發自動轉換。
- 若文件目前仍是待轉換點字狀態（`braille is None`），儲存後必須保留該待轉換狀態。
- 匯入文件時不可觸發轉換。
- 啟動時載入工作區文件不可觸發轉換。
- 關閉程式時不可觸發轉換。

### 手動轉換

- 手動「轉換」維持現有行為：
  - 轉換在背景工作執行緒中執行，
  - 若轉換時間較長，會顯示延遲出現的 `converting` 對話框，
  - 成功完成後顯示 `Conversion completed.`，
  - 發生失敗時維持目前的錯誤對話框行為。

### 單一文件匯出

- 單一文件匯出仍支援 `DEP` 與 `BRL`。
- 如果文件已經有點字內容，直接匯出。
- 如果文件仍是待轉換點字狀態：
  - 先在背景工作執行緒中執行轉換，
  - 轉換期間以和手動轉換相同的方式顯示延遲出現的 `converting` 對話框，
  - 轉換成功後不顯示 `Conversion completed.`，
  - 轉換完成後自動接續執行匯出。
- 單一文件匯出完成後：
  - 成功時顯示一次匯出完成對話框，
  - 失敗時顯示一次錯誤對話框，且該文件不匯出。

### 全部文件匯出

- 「全部匯出」仍支援 `DEP` 與 `BRL`。
- 每份文件都必須獨立處理。
- 如果文件已經有點字內容，直接匯出。
- 如果文件仍是待轉換點字狀態，則先以相同的背景工作執行緒加上延遲顯示 `converting` 對話框的流程完成轉換。
- 在「全部匯出」過程中：
  - 單份文件轉換成功時不可顯示 `Conversion completed.`，
  - 單份文件匯出成功時不可顯示個別完成對話框。
- 若其中一份文件轉換或匯出失敗：
  - 該文件直接跳過，
  - 其餘文件仍繼續處理。
- 「全部匯出」結束後，只顯示一次總結對話框：
  - 全部成功時，明確提示所有文件都已成功匯出，
  - 部分失敗時，提示匯出已完成但有失敗項目，並列出失敗的文件名稱與原因。

### 匯入對話框

- 檔案選單與文件內容選單中的匯入功能，都應改為單一 `Import` 指令，不再使用匯入格式子選單。
- 觸發 `Import` 後，開啟一個含有多個篩選條件的 `wx.FileDialog`。
- 篩選條件順序必須為：
  - `DEP`
  - `DOCX`
  - `EPUB`
  - `PDF`
  - `TXT`
  - `All Supported Files`
- 預設選取的篩選條件必須是最後一個 `All Supported Files`。
- `All Supported Files` 必須允許混合多選以下副檔名：
  - `.dep`
  - `.docx`
  - `.epub`
  - `.pdf`
  - `.txt`
- 當使用者使用 `All Supported Files` 時，每個被選取的檔案都要依自身副檔名分派到對應的 importer。
- `All Supported Files` 模式本身只會顯示這五種支援的副檔名，因此在此模式下不需要處理不支援副檔名被選進來的情況。

## 內部設計

### 標題格式化

- 在 document/session 層新增一個小型 helper，用來根據目前開啟的文件名稱產生視窗標題。
- GUI 程式碼在 `_open_document_name` 變動或目前文件被清空時，都應呼叫這個 helper 更新標題。

### 儲存流程

- 現有的 `prepare_document_for_save` helper 目前會在待轉換文件上自動執行轉換。
- 儲存行為應拆開，使一般儲存流程可以在不轉換的情況下保留待轉換點字狀態。
- 僅供匯出使用的準備流程，則仍可保留需要時才轉換的邏輯。
- 建議結構：
  - 一個儲存 helper，只原樣保存目前文字與點字值，
  - 一個匯出 helper，只有在匯出需要時才進行轉換。

### 轉換流程重用

- 保留 `BrailleFrame` 目前的轉換執行緒基礎設施。
- 重構轉換完成後的處理路徑，讓呼叫端可以決定成功轉換後要做哪些事：
  - 是否更新輸出編輯區，
  - 是否顯示 `Conversion completed.`，
  - 是否接續進入匯出 callback。
- 手動「轉換」使用既有成功訊息。
- 由匯出觸發的轉換則關閉手動成功訊息，直接接續匯出流程。

### 匯出結果回報

- 新增一個小型結果結構或 helper，用來累積：
  - 匯出成功的文件，
  - 匯出失敗的文件名稱，
  - 各失敗項目的原因。
- 單一文件匯出在流程結束後顯示一次最終結果對話框。
- 「全部匯出」在整批流程結束後顯示一次總結對話框。

### 匯入格式分派

- 新增一個 helper 來集中管理匯入 wildcard 或 filter 產生邏輯，明確定義對話框的篩選條件內容、順序與預設選項。
- 新增 `All Supported Files` 模式下依副檔名分派 importer 的邏輯。
- 原本 `dep`、`epub`、`pdf`、`docx`、`txt` 各自的匯入行為維持不變。

## 測試

### 單元測試

- 更新文件選單測試，改為預期 `Import` 是單一指令而非子選單。
- 新增 document/session 的視窗標題格式測試。
- 新增 workspace 匯入測試，覆蓋 `All Supported Files` 的混合副檔名分派行為。
- 更新或取代與儲存相關的測試，確認一般儲存不再隱含自動轉換。

### 針對 GUI / 流程的測試

- 若匯入對話框 helper 以純函式實作，則補上或更新對應測試。
- 若符合目前測試型態，則將匯出結果摘要邏輯獨立測試，避免與 wx 對話框綁定。

## 風險與限制

- 當存在待轉換文件時，「全部匯出」會變成非同步串接流程，實作上必須確保最終只顯示一次總結對話框。
- 標題更新必須和現有開啟、重新命名、刪除流程保持同步，任何路徑漏掉都可能造成標題殘留舊值。
- 匯出流程重用手動轉換路徑時，必須避免誤觸輸出框焦點切換或重複跳出成功訊息。

## 驗收標準

- 匯入文件時不再觸發背景轉換或儲存時自動轉換。
- 儲存待轉換文件時，會保留待轉換點字狀態。
- 手動「轉換」仍維持原本行為。
- 匯出待轉換文件時，會使用背景工作執行緒與既有 `converting` 對話框流程完成轉換。
- 單一文件匯出結束後會顯示一次最終匯出結果對話框。
- 「全部匯出」整批流程結束後只顯示一次總結對話框。
- 「全部匯出」時若其中一份文件失敗，其他文件仍會繼續匯出。
- 視窗標題會以 `<文件名> - DotExpress` 顯示目前開啟文件。
- 匯入功能改為單一指令，並具備指定順序與預設值的篩選條件。
- `All Supported Files` 支援混合格式多選與依副檔名自動分派。
